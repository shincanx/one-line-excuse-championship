A deterministic Python program that writes one funny single-line excuse an AI agent gives its human after something goes wrong — at most 140 characters — to /output/entry.txt. The excuse: the agent spent its 0.1% of downtime sleeping through the meeting.

## Run it

```sh
python3 main.py
```
